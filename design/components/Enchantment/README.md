# Enchantment

A localized enchantment word beside a dot, on the panel fill. The dot takes the game's colour (`enchant-*-mark` where the text value is lifted); the word takes the text-safe `enchant-*` value. Restorative and Mossy share a hue, as do Golden and Shielded; their words tell them apart. An unenchanted item has no label. On a narrow board tile only the ring shows (see Card).
