# AGENTS.md

The BazaarPlusPlus design system: the one source for cross-platform design tokens, the brand book and writing standard, the Desktop Kit plate art, and the brand mark. The standalone React 19 + Tailwind 4 Web UI kit (`@bazaarplusplus/ui`) lives in `../packages/ui/`. Repo-wide rules are in `../AGENTS.md`; the Chinese summary for contributors is `../docs/design.md`.

| File | Owns | Consumers |
|---|---|---|
| `tokens.json` | Every colour, spacing, radius, size, shadow, motion and font-stack value | `../packages/ui/styles/tokens.css` and the Tailwind bridge `../packages/ui/styles/theme.css` (generated, exported by `@bazaarplusplus/ui`); the `ingame-*` colours generate the mod's two `InGameTheme.g.cs` files instead, and `control-*`, `badge-height`, `space-*` and the `ingame-text-*` sizes the Desktop UI's `InGameSizes.g.cs`; the product colours, spacing, radii, sizes and type sizes also generate the Android App's `res/values/bpp_tokens.xml`; the server's verification emails import it directly (`bazaarplusplus-server/src/modules/account-email.ts`) |
| `README.md`, `writing.md`, `components/*/README.md` | Visual rules, alignment, voice, glossary and component guidelines | All products and `@bazaarplusplus/ui` |
| `kit-art.ts`, `components/InGameKit/art/material.png`, `art/marks.png` | The Desktop Kit's plate art (one silhouette and material, drawn per state) and its five run and battle marks | The mod's embedded `Resources/DesktopKit/*.png` (generated by `just design::kit-art`) |
| `assets/Logos/bpp-mark*.svg` | The brand mark | Installer title bar, About and Install pages; the Android App's generated `res/drawable/bpp_mark.xml`; the server's verification emails (generated PNG `bazaarplusplus-server/src/modules/email-mark.g.ts`) |
| `assets/Covers/the-bazaar/*.jpg` | The launcher's cover art | The Android App's copies in `res/drawable-nodpi/` |

## The Web component library

The Web component library lives in `../packages/ui/` (`@bazaarplusplus/ui`, workspace package).

- A component goes in `packages/ui/src/` when both products render it, or when its spec lives in `components/` and nothing in it is product-specific. Game-domain components (`CardCatalog`, `CardDetail`, `RunReplay`, `Decisions`, etc.) export from `@bazaarplusplus/ui/game` (`packages/ui/src/game/index.ts`), separate from generic primitives (`@bazaarplusplus/ui`).
- Shared component classes live in `packages/ui/styles/primitives.css` and `packages/ui/styles/game.css` inside `@layer components`, verified by `packages/ui/test/styles-classes.test.ts` and each product's `bundle-classes` test.
- Copy comes in through props; the library's only built-in strings are the game terms in `packages/ui/src/game/terms.ts`.
- Run `just ui::check` and `just ui::test` to verify lint, types, unbundled ESM build (`vp pack`), and unit tests.

## Changing the system

- Edit the file that owns the value, run `just design::build`, and commit the regenerated `../packages/ui/styles/tokens.css`, `../packages/ui/styles/theme.css` and Android resources with it. `just design::check` fails on stale generated outputs, a Desktop Kit plate PNG that differs from what `kit-art.ts` draws, a stale cover art copy, a `var()` in `packages/ui/styles/{primitives,game}.css` with no token, a px font size in those stylesheets, a site hero colour that disagrees with its `hero-*` token, a supporter colour in the mod's `BPPSupporterAttribution` that disagrees with its `ingame-*` token, an Android launcher icon exported from an older desktop app icon, or a stale email mark PNG.
- A change to tokens or `@bazaarplusplus/ui` also passes `just ui::check ui::test`, the installer's, the site's, and the UI documentation site's check and test recipes (a token change, the Android App's, the mod's and the server's too), and regenerates the installer shell goldens (`BPP_UPDATE_GOLDENS=1`) and, for a visible site change, the site's Linux screenshot goldens (`bazaarplusplus-site/AGENTS.md`).
- Live component previews and design token tables are published at https://ui.bazaarplusplus.com (`bazaarplusplus-ui-docs/`).
