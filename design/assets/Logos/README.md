The BazaarPlusPlus marks. The brand mark is a flat chevron over a gem. The app icon and the menu-bar mark are the original artwork from the repository, copied byte for byte.

- `bpp-mark.svg`: the brand mark for dark grounds. The chevron is `text-1` (#edebe7) and the gem `accent` (#ee8e1f), on a 32-unit grid. Use it in the title bar (20px) and on the Install status panel. The site header uses `bazaarplusplus-site/public/bazaarplusplus-icon.webp`.
- `bpp-mark-on-light.svg`: the same mark with the chevron in `bg-selected` (#2c2a27) ink, for light grounds.
- `bpp-mark-mono-white.svg`: a single white ink (#ffffff) for the macOS menu bar and other one-colour places. It is invisible on light grounds.
- `bazaarplusplus-icon.webp`: the app icon (silver chevron, amber "++" gem and BAZAAR++ plate on a dark squircle, 256px), as shipped by the site.
- `favicon.webp`: the site's browser-tab icon (128px).
- `app-icon.png`: the 1024px master of the desktop app icon, from which the .icns and .ico files are built.
- `tray-macos.svg`: the shipped macOS menu-bar mark, a single white ink. `bpp-mark-mono-white.svg` is its flat successor.
