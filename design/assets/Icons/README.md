The site's icon set (`bazaarplusplus-site/src/shared/components/icons.tsx`): Lucide paths (ISC) on a 24px grid, stroke 2, round caps and joins.

- In code they draw in `currentColor`. These files fix the stroke to `text-2` (`#a5a19a`) so they show as images; recolour them in code, not here.
- The installer uses the same family from `lucide-react`: Download, History, MonitorPlay, Info, Languages, Heart, Coffee, TriangleAlert, CircleX, CheckCircle2, Loader2, X, ChevronDown/Right, Folder, FolderClock, FolderX, Database, HardDrive, Play, RefreshCw, Copy, Clipboard, QrCode, ShieldCheck, Users and BookOpen, among others.
- `spinner.svg` is Loader2's arc. It rotates 0.8s linear while busy.
