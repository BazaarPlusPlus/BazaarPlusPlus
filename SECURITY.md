# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull requests, or
discussions. Instead, report them privately via
[GitHub Security Advisories](https://github.com/BazaarPlusPlus/BazaarPlusPlus/security/advisories/new).

Please include a description of the issue, steps to reproduce, the affected version, and its
potential impact. We will acknowledge your report within 7 days and keep you informed of our
progress. Only the latest release receives security fixes.
