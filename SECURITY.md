# Security Policy

## Supported versions

Only the latest Product Release gets security fixes. The installer updates itself, and the mod
ships with it, so a fix reaches players through the next release.

## Reporting a vulnerability

Report privately through GitHub: **Security → Report a vulnerability** on this repository
([direct link](https://github.com/BazaarPlusPlus/BazaarPlusPlus/security/advisories/new)).
Do not open a public issue, pull request, or discussion for a vulnerability.

Include the affected project (mod, installer, server, analyzer, or site), the version or commit,
steps to reproduce, and the impact you expect. We aim to acknowledge a report within 7 days.

In scope:

- The mod and the desktop installer, including install, repair, update, and the updater signature.
- The upload backend at `mod-api-v5.bazaarplusplus.com` and the data it stores or serves.
- bazaarplusplus.com and its download page.

Out of scope: The Bazaar itself, BepInEx, and other third-party components, which should be
reported to their own maintainers.
