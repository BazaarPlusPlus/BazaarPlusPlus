# QQ Bot

**Binding**: one QQ `member_openid` mapped to one game account and the display name used to bind it. It is independent of a group; multiple QQ users may bind the same game account. It is a visibility opt-in, not proof of ownership. Anyone may query an account while at least one Binding references it. Unbind removes only the caller's Binding.

**Player Report**: a freshly calculated view of completed Accepted Runs ending within the Beijing calendar day of the query and the two days before it. It retains no Run or Battle data after the job. Accepted Run, Ten-Win Run and Build Identity follow the analyzer glossary; Bundle and Run follow the root glossary.
