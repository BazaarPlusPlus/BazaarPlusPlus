# 随卡图发布物品附魔材质

状态：已接受（2026-11-25）

## 背景

ADR 0020 的 RGB 插图能还原物品外观。游戏还按材质遮罩的不同通道决定冰晶、烟雾和闪光的位置。同一种附魔在不同物品上的位置和比例取决于该物品的材质。

## 决定

扩展 ADR 0020 的公开资源范围，在卡图前缀发布物品材质描述、每张卡的附魔遮罩及各材质共用的特效纹理。原始资源包、粒子预制件和着色器程序留在提取端。此处单独承担公开分发这些派生资源的取舍，ADR 0012 的 interop 授权范围不包含它们。

按 GameData 的 ArtKey 找到 Steam online 卡牌材质，从纹理包解析引用，从卡牌着色器包补齐参数默认值。普通皮肤使用既有插图，遮罩及共享纹理保留源尺寸和 RGBA 通道。材质描述记录渲染配置、原始尺寸类别、常规与 Tiny 模式的关键字组合、参数、纹理地址及采样设置。多张卡可以引用同一份纹理，采样方式和 UV 变换随材质保存。纹理的 wrap、filter 和 colorSpace 保留 Unity 枚举值，st 依次记录 U、V 缩放和偏移。PNG 保存基础级别，mipCount 记录原纹理的级数。着色器声明的默认纹理按名称保留，无法解析的非空引用会使该物品跳过特效提取。

沿用 v2 索引，增加可选的 fx 映射。旧索引缺少此字段时展示普通卡图。不可变文件全部就绪后再切换索引，游戏移除的 ID 保留最后一次发布的材质。当前卡牌缺少可解析的材质时仍可展示普通卡图。ADR 0021 继续管理本地化文本。

## 备选方案

- BazaarDB 接口依赖第三方服务，无法用本项目的 Steam 快照复现。
- 每个物品、每种附魔烘焙一张图，按 1,428 个物品、16 种附魔、每图 24 KiB 估算，一套约 536 MiB，动画还需要更多帧。
- CSS 颜色和边框足以提示附魔种类，无法表达材质驱动的纹理位移和局部明暗。
